## Feature prioritisation rule

A feature should move forward only when it improves one of these outcomes:

1. Better career discovery
2. Better recommendation quality
3. Better participant completion
4. Better safety or trust
5. Lower justified operating cost
6. Better evidence and learning

Features that only make the product look larger should wait.
