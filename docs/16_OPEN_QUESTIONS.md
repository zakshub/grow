# Open Questions

## Purpose

This file records unresolved decisions that should not be silently guessed during design or implementation.

## Decision discipline

When one of these questions is resolved:

1. Update the relevant canonical document
2. Record the rationale
3. Remove or mark the question resolved here
4. Avoid leaving conflicting rules in multiple files

The open questions list should shrink as evidence improves and grow when new uncertainty is discovered.
