# Grow Product Brain Index

This directory is the canonical planning and intelligence layer for Grow.

## Strategic foundation

1. `01_PRODUCT_VISION.md`
Defines the problem, long term vision, product thesis, positioning, and non goals.

2. `02_AUDIENCE_AND_SCOPE.md`
Defines the core audience, flexible age logic, geography, use cases, and expansion boundaries.

3. `03_CAREER_DISCOVERY_ENGINE.md`
Defines the core career consultant module that discovers interests, personality signals, strengths, values, and realistic career directions.

4. `04_ASSESSMENT_MODEL.md`
Defines the multi dimensional assessment model and explains why no single personality type should determine a career.

## Participant experience

5. `05_PARTICIPANT_JOURNEY.md`
Defines the end to end participant journey from first contact to recommendation, trial, roadmap, follow up, and referral.

6. `06_WHATSAPP_OPERATING_MODEL.md`
Defines WhatsApp as the primary participant interface and describes the conversation states, reminders, escalation, and operator experience.

7. `07_RECRUITMENT_AND_REFERRALS.md`
Defines how participants are sourced, approached, referred, qualified, and tracked.

8. `08_FEES_AND_ACCESS.md`
Defines standard fee, reduced fee, free access, dignity principles, and human review.

## Trust and operations

9. `09_DATA_PRIVACY_AND_SAFETY.md`
Defines data boundaries, minors, guardian consent, sensitive information, retention, and human review.

10. `10_SYSTEM_ARCHITECTURE.md`
Defines the future self hosted application architecture around WhatsApp, data storage, workflow orchestration, analytics, and AI services.

11. `11_AUTOMATION_BLUEPRINT.md`
Defines which workflows should be automated, which require a human, and how escalation works.

## Delivery

12. `12_MVP_BUILD_PLAN.md`
Defines the smallest useful version that can be tested with real participants.

13. `13_ROADMAP.md`
Defines phased growth from manual assisted pilot to national scale.

14. `14_MEASUREMENT_AND_LEARNING.md`
Defines funnel, quality, recommendation, retention, outcome, and learning metrics.

15. `15_RESEARCH_AND_EVIDENCE.md`
Defines evidence standards, external framework research, labour market evidence, and knowledge promotion.

16. `16_OPEN_QUESTIONS.md`
Tracks unresolved product, operational, assessment, business, and technical decisions.

## Canonical rule

If future implementation, design, research, or automation conflicts with these documents, the conflict should be surfaced explicitly rather than silently overriding the product brain.

The product brain should evolve through documented evidence and decisions, not ad hoc changes.
