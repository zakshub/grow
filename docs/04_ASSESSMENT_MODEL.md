# Assessment Model

## Purpose

Grow needs a structured assessment model that is broad enough to understand a person but simple enough to work through WhatsApp.

The model should borrow useful ideas from established personality and vocational frameworks without pretending that one commercial quiz can determine a career.

## Assessment philosophy

Career direction should be inferred from patterns across several dimensions.

Grow therefore separates:

1. Personality tendencies
2. Interests
3. Current strengths
4. Potential and learning speed
5. Work values
6. Work environment preferences
7. Practical behaviour
8. Constraints

These dimensions should not be collapsed into one score.

## Question design

Do not rely only on statements such as I am logical or I am creative.

Use multiple formats:

1. Behavioural examples
2. Forced choices
3. Situational judgement
4. Preference ranking
5. Short reasoning tasks
6. Reflection questions
7. Practical mini tasks
8. Follow up questions when answers conflict

## Adaptive questioning

The system should not ask every participant every question.

It should begin broad, then deepen where uncertainty is high.

Example:

If a participant repeatedly shows analytical interest but low evidence about persistence, the next questions should explore sustained problem solving rather than repeat analytical questions.

## Contradiction handling

Contradictions are useful evidence.

Example:

A participant says they love public speaking but repeatedly avoids speaking tasks.

Do not mark one answer wrong immediately.

Explore possibilities:

1. They like the idea more than the activity
2. Anxiety interferes with an actual interest
3. Context matters
4. Previous bad experiences distort behaviour
5. The task design was poor

The system should record unresolved contradictions.

## Scoring principle

Scores should be treated as estimates with confidence.

Example:

Logical reasoning: 78

Confidence: moderate

Evidence:

1. Three structured reasoning tasks
2. Two behavioural examples
3. One contradictory self report

This is stronger than displaying 78 without context.

## Suggested score interpretation

0 to 24: weak current signal

25 to 49: limited or mixed signal

50 to 69: moderate signal

70 to 84: strong signal

85 to 100: very strong signal

These thresholds are provisional and must be validated with real data before being treated as stable rules.

## Career matching model

A future matching function can consider weighted compatibility across:

1. Interest fit
2. Strength fit
3. Personality fit
4. Value fit
5. Environment fit
6. Constraint feasibility
7. Practical experiment fit
8. Market viability

Weights should not be fixed permanently without validation.

## Example career profile

A career such as user experience research may require a pattern including:

1. Curiosity
2. Research orientation
3. Listening
4. Pattern recognition
5. Communication
6. Tolerance for ambiguity
7. Empathy
8. Analytical reasoning

A participant does not need maximum scores in every dimension.

The system should look for viable patterns rather than perfect profiles.

## Assessment integrity

Avoid:

1. Copying proprietary question banks
2. Claiming clinical validity without validation
3. Presenting results as diagnosis
4. Hiding uncertainty
5. Using culturally loaded questions without review
6. Assuming urban English speaking behaviour represents Pakistan broadly
7. Using gender stereotypes in career mapping

## Validation plan

Before the assessment model is trusted at scale:

1. Test questions with small cohorts
2. Interview participants after results
3. Compare self perception with observed behaviour
4. Ask human career reviewers to challenge recommendations
5. Track whether practical experiments confirm or reject hypotheses
6. Measure whether participants understand their result
7. Track later outcomes where consent exists
8. Revise weak dimensions and questions

## Output rule

The participant should receive an understandable narrative, not a wall of scores.

Scores support reasoning internally.

The participant output should explain:

1. What patterns appear strongest
2. What evidence supports them
3. What is still unclear
4. Which career families fit
5. What should be tested next
