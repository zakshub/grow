# Participant Journey

## Goal

Design one coherent journey from first awareness to useful career direction and later follow up.

## Journey stages

### Stage 1: Awareness

Participant hears about Grow through:

1. Friend or family referral
2. Old student network
3. Teacher or institution
4. WhatsApp forwarding
5. Community network
6. Social media
7. Local outreach

Goal: create enough trust and curiosity for the participant to start a WhatsApp conversation.

### Stage 2: Entry

Participant sends a simple message through WhatsApp.

The system should immediately explain:

1. What Grow does
2. What it does not do
3. Approximate time required
4. Fee model
5. Privacy basics
6. That answers should be honest rather than impressive

### Stage 3: Consent and profile

Collect:

1. Name
2. Age
3. Education level
4. City
5. Current study or work status
6. Preferred language
7. Guardian consent where required

Only collect information that is useful.

### Stage 4: Discovery conversation

Use conversational questions to understand:

1. Current confusion
2. Past interests
3. Activities
4. Strength stories
5. Frustrations
6. Family context
7. Career pressure
8. Goals
9. Constraints

### Stage 5: Structured assessment

Run adaptive assessment for:

1. Personality tendencies
2. Interests
3. Strengths
4. Work values
5. Environment preferences
6. Relevant reasoning signals

### Stage 6: Initial interpretation

Create an internal summary:

1. Strong signals
2. Weak signals
3. Contradictions
4. Missing evidence
5. Possible career clusters
6. Questions requiring deeper exploration

### Stage 7: Practical experiments

Give one or more small tasks that resemble real work.

The participant should understand why the task is being given.

### Stage 8: Review

Combine:

1. Assessment evidence
2. Conversation evidence
3. Practical task evidence
4. Constraints
5. Market evidence

### Stage 9: Recommendation

Deliver:

1. Personal pattern summary
2. Top career directions
3. Why each fits
4. Tradeoffs
5. Education requirements
6. Learning path
7. Earning reality where evidence exists
8. Next actions

### Stage 10: Decision support

Allow questions such as:

1. Which of these options is best for me
2. What if my parents prefer another field
3. What if I cannot afford university
4. Which skill should I test first
5. Can I earn before completing a degree

### Stage 11: Action roadmap

Create a practical roadmap covering the next weeks or months.

Possible outputs:

1. Subjects to explore
2. Skills to learn
3. Free resources
4. Small projects
5. People to talk to
6. Courses to compare
7. Degree options to research
8. Portfolio tasks

### Stage 12: Follow up

Check whether the participant actually acted.

Suggested follow ups:

1. After 7 days
2. After 30 days
3. After 90 days
4. After a major education or career decision

### Stage 13: Learning loop

Ask:

1. Did the recommendation still feel accurate
2. Which experiment was most useful
3. What changed
4. Which option was chosen
5. What did Grow misunderstand

### Stage 14: Referral

Participants who found value can refer people who are genuinely confused and willing to engage seriously.

Track the referral source so acquisition quality can be measured.

## Dropout recovery

If the participant stops responding:

1. Send one respectful reminder
2. Offer to continue later
3. Avoid repeated pressure
4. Preserve progress if consent and retention policy allow

## Human escalation points

Escalate when:

1. The participant is a minor and guardian action is required
2. Answers indicate serious safeguarding concern
3. Career evidence remains highly contradictory
4. Financial support requires judgement
5. Participant challenges a sensitive recommendation
6. The system cannot answer with adequate confidence

## Experience rule

The participant should always know:

1. Where they are in the process
2. Why a question is being asked
3. What happens next
4. When a human is reviewing something
5. Which parts of the recommendation are uncertain
